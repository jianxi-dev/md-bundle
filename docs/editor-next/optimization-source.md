## 1. 设计哲学（从豆包实证，直接约束实现）

| 编号 | 原则 | 对实现的硬约束 |
|---|---|---|
| **P0** | **悬停即显，零点击** | 手柄 / 菜单 / 热点 / 空行「+」/ 子菜单，**悬停出现**；点击只用于"确认动作"，不用于"召唤控件" |
| P1 | 静默画布，浮层表达 | 编辑态**不新增常驻控件**；能力只在悬停/需要时出现 |
| P2 | 一个手柄，两种意图 | 42×26 药丸：左=块型图标（转为），右=拖拽把手（菜单/拖拽）；**空行退化为单个「+」** |
| P3 | 图标即词汇 | 手柄显示**该块自己的类型图标**；每个动作有专属图标；**能用可视符号绝不用文字**（如文字颜色用彩色「A」字母） |
| P4 | 上下文感知 | 同一手柄按块型给不同菜单（列表/高亮/表格各不同） |
| P5 | 一致下钻语法 | `›`=悬停 flyout；`▾`=弹出面板；**图标网格**=快速转换；**文字列表**=需说明的动作 |
| P6 | 尺寸与色彩阶梯 | 圆角 8/6/4；图标 18/24；行高 32；品牌蓝 `#547cff`；悬停 `rgba(235,235,235,.08)` |
| P7 | 克制动效 | 极短进入动画 + 淡入淡出，不弹跳 |

## 3. 交互规格（逐面 · 可直接转 openspec requirement）

> 证据标注：`E:` 后为实测来源（截图名 / DOM 类名 / `data-icon`）。所有"空白"显式标记为 `open-question`，**禁止想当然补**（QG-8）。

### 3.1 块手柄（悬停驱动）
- 悬停块行 → 手柄药丸淡入：**块型图标 + 拖拽把手**（空行 → 单个「+」）。`E: r01, s13b, crop-handle`
- **悬停手柄本身 → 块菜单自动展开**（无需点击），该块获得蓝色选中态。`E: r08`
- 菜单打开时向手柄→菜单移动，**不消失**（命中桥接）。`E: 交互一致`
- 块型图标 → 转为；把手 → 菜单/拖拽。`E: 手柄 DOM`

### 3.2 块菜单（上下文感知 + 二级）
- 布局：`问问豆包`（本轮**不做**，见 §2.2）→ 分隔 → **转为图标网格** → 分隔 → 面板项。`E: 02-block-menu`
- 转为网格（图标、无文字）：正文 / H1 / H2 / H3 / 有序 / 无序 / 待办 / 代码 / 引用 / 高亮。`E: data-name`
- 面板项：`缩进和对齐 ›`（左/中/右对齐 + 增加/减少缩进）、`颜色 ›`（字体色 + 背景色 + 恢复默认）、评论（不做）、剪切、复制、删除（危险色）、在下方添加 ›。`E: 03-menu-align, 04-menu-color`
- **上下文分型**：高亮块菜单含 **类型/颜色二级**（见 §3.6）；表格菜单含表格专属项（见 §3.5）。

### 3.3 插入菜单 & 快捷输入（**本轮重点**）
- **触发键：`/`（中英文均可）与 `、`** —— 两种字符都触发；输入法下同样生效（IME 守卫）。`open-question: 中文全角「／」是否也触发？待定》
- 形态：**带分类标题的纵向列表**（不是图标网格）：基础 / 常用 / 绘图 / 团队协作（本轮仅保留"基础 / 常用 / 绘图"，其余见 §2.2）。`E: r05, 13-slash, 用户实图`
- 条目 = 左图标 + 名称；命中项高亮。
- **表格项带 `›`**：悬停展开**「插入支持富文本的表格」尺寸选择器**（网格选行列数）；直接点选则插默认 2×3。`E: r06-table-flyout`
- **分栏项带 `›`**：悬停展开**「选择栏数」**条形选择器。`E: r07-col-flyout`
- **二次过滤（本轮重点）**：打开菜单后**继续输入即筛选**；筛选需支持：
  1. 中文名称匹配（如输入「表」匹配 表格/电子表格）；
  2. **首字母/拼音/单键码匹配**（承接我们特色：`/t` → 表格/任务；`/t53` → 5 行 3 列）；
  3. **命中二级菜单项**：当筛选词命中某个带 `›` 的一级项时，**直接展示其二级项**（如输入「表」→ 直接列出「插入支持富文本的表格」的选项，避免用户再悬停）。`open-question: 二级项在筛选态如何与一级项混排？待定》
- **取消无残留**：Esc / 点外部取消后，文档**不得**残留触发字符（`/` `、`）。`E: D6`
- **关闭语义**：点外部 / 光标移走 → 关闭（不能只认 Esc）。`E: D4`
- **空态**：无匹配 → 显示"无匹配项"**且可退出**，不得驻留空框。`E: D5`

### 3.4 选区浮动工具栏
- 文本/单元格选区 → 浮层工具条。表格选区含：**合并单元格**（多格时启用）、**单元格背景色**、转为 `▾`、对齐 `▾`、B / S / I / U / `</>`（行内码）、高亮 `▾`、更多、分享（不做）、评论（不做）。`E: 10b, 12-cell-bg`
- **颜色面板**：字体色用**彩色「A」字母**；背景色用色块；「恢复默认」。`E: 04-menu-color, 用户强调`

### 3.5 表格（**本轮重点，且不得坍缩源码**）
- **滑入单元格（未点击）** → 单元格**左侧线上**浮现**格内块手柄**（块型图标 + 把手；空格 → 「+」）。`E: s13b`
- **悬停格内手柄 → 展开「插入菜单」**：基础（图标网格 12 项）+ 常用 + 绘图 + 团队协作。`E: 用户实图 s15`（**注意：不是块菜单，见 §5 教训 T-1**）
- **行/列插入锚点在「单元格之间的线」上**：列「+」在**两列之间竖线**（列左边界，偏差 −1px）、行「+」在**两行之间横线**；悬停高亮的是**一条边界线**（竖线/横线 + 气泡 插入列/插入行），**不是整列/整行底色**。`E: u04-crop, r04c`
- **表块菜单**（点左上 `DataSheetOutlined`）：缩进 ›、剪切、复制、删除、`标题行`（开关）、`标题列`（开关）、`均分列宽`、在下方添加 ›。`E: 06-table-menu`
- **单元格选区工具栏**：见 §3.4。
- **不得坍缩源码**：在任何情况下（点击单元格、编辑内容），表格**都不得整表塌成裸 Markdown**；必须保持可视化表格 + 单元格内可编辑。`E: D7`
- **插入后的表格**：须有真实尺寸（由尺寸选择器决定）、合理列宽、单元格可编辑；**不得**是 `A/B/1/2/3/4` 玩具占位。`E: D8`

### 3.6 高亮块（**多种二级选项 + 不得坍缩源码**）
- 渲染态卡片（emoji + 底色），**标题不得重复**（D2：曾出现「注释 注释」）。
- **二级选项**（我们已有多种）→ 放进**「含二级菜单的区域」**：块菜单里的 `属性/类型 ›` 二级（note/info/tip/success/warning/danger/error/question + 颜色 + emoji + 折叠）。`E: 上轮 editor-callout-editing》
- **不得坍缩源码**：编辑高亮块时**不得**整块切换成 `> [!NOTE]` 源码；必须卡片内联编辑（含末字符后仍可续输，修复历史 D2/边界吞字）。
- emoji 选择器：点 emoji 打开（复用豆包 emoji-mart 交互形态）。`E: 22b`

### 3.7 分栏
- **每一栏滑入都出现块手柄**（对栏内容做块级操作）。`E: u01-grid`
- 栏间是**可拖拽栏沟**：悬停高亮竖线，`cursor: col-resize`，**按住左右拖拽改变栏宽**。`E: u01-grid + DOM .dragger`
- 栏数由插入菜单「分栏 › 选择栏数」决定（我们支持 1–5）。

### 3.8 任务 / 待办
- 复选框可点击勾选（勾选后文字变灰）；编辑态**直接可点**。
- 行尾悬停出现工具（豆包为「转为任务」）；我们的形态待定。`open-question`

### 3.9 视频/文件 与 流程图（本轮要做）
- **视频/文件**：插入 → 渲染为可识别卡片/播放器（沿用我们已实现的 file 引用 + renderer 白名单）。`E: 上轮 4.6`
- **流程图**：以 Mermaid fenced code 表达，编辑态预览 + 渲染态出图（复用 renderer 的 mermaid）。**不得**坍缩源码。

### 3.10 图标系统
- 统一 `<svg data-icon="XxxOutlined">`，viewBox 24×24，currentColor；**建立"块型→图标""动作→图标"映射表**（本轮把零散字符/简易 SVG 全部替换）。`E: 78 个真实图标已提取`
- 手柄显示块型图标；空行「+」= `AddOutlined`。

### 3.11 快捷键（豆包没有，我们要保留 + 显示）+ 命令面板重设计
- 保留全部特色快捷键（斜杠单键码、`Mod-Alt-1..6`、`Mod-Shift-7/8/9`、`Mod-K` 等）。
- **优化点**：快捷键要**在真实菜单中显示**——**除"仅图标"的项外**，每个有快捷键的菜单项都要标出键位（如 `复制 ⧉  ⌘C`）。`E: 用户强调 3`
- **命令面板（⌘K）重设计**（现状不好看、需重做）：
  - 现状三硬伤：**CSS Grid 排命令**（`repeat(auto-fill,minmax(190px,1fr))` → 键位被挤、行不对齐）；**无简介**（代码只渲染 label+keyBinding）；**网格中 ↑↓ 跨列乱跳**。`E: command-palette.ts / -dom.ts`
  - 目标形态：**单列 + 键位右对齐**（图标｜名称｜简介｜…｜键位）；**分组吸顶 + 顶部「最近使用」**；**模糊 + 拼音 + 命中高亮**；**单列顺序导航**（选中态=品牌淡底+左侧 2px 强调条）；**底部键位提示条**；分类 chip 可限定分组；空态给建议。
  - 价值主张（为何保留）：豆包没有=差异项；是**快捷键唯一全量入口**（可发现性）；40+ 命令比逐级菜单快。
  - 设计稿与可交互原型：`.lavish/command-palette-design.html`（含现状对照 + 交互原型 + 设计规格）。

### 3.12 编辑态视觉 = 预览态（渲染与样式 SSOT）★新增核心需求
- **现状问题**：编辑态用 CM6 装饰**近似还原**，DOM 用 `.cm-*`，预览态用 `.preview-content *`，**两套样式分叉** → "编辑态不如预览态好看"。`E: 用户反馈`
- **目标**：同一段 Markdown，**编辑态与预览态视觉一致**（逐块计算样式 / 像素级）。
- **手段（按优先级）**：
  1. **渲染 SSOT**：编辑态的块装饰改为**逐块调用 `@md-bundle/renderer`**（`renderMarkdown`），产出与预览/导出**完全相同**的 HTML，消灭"近似还原"。
  2. **样式 SSOT**：编辑态内容区套用 `readerCssText` 的等价作用域（与 `.preview-content` 同源），消灭两套 CSS。
  3. **活动块源码桥**：光标所在块显示源码（或"源码浮层"），离开即回渲染态 —— 保留 live-source 可编辑性（ADR-0002）。
  4. **性能**：按块**增量渲染 + 缓存**（未变更块不重渲染）；KaTeX / mermaid 走 `hydrateLazyFeatures`。
- **验收（保真 + 视觉探针）**：同一段 markdown（标题/列表/表格/高亮块/代码/KaTeX）在**编辑态与预览态逐块计算样式相等**；并排截图复核。
- **风险 / 待决（需一条 ADR 或 design 决策）**：大文档逐块渲染的性能；光标 ↔ 源码映射；装饰与源码边界吞字；IME 组合态。
- **与 §3.5/§3.6 的关系**：本项把"表格 / 高亮块**不坍缩源码**"**推广为全部块的**"预览态渲染 + 活动块源码"——即"编辑比预览好看"的根因解法。

## 4. 我们要保留的差异（不照抄豆包）

1. **底层永远是 live Markdown 源码**（ADR-0002）——编辑态采用「**预览态渲染 + 活动块源码**」（§3.12）；**表格 / 高亮块至少不得坍缩源码**（§3.5 / §3.6）。这是与豆包一致的取向，也是本轮的硬约束。
2. **快捷键体系**（豆包无）——保留并在菜单显示（§3.11）。
3. **三模式 + 命令面板 + 多页签 + FSA + 主题三态 + 邀请链接**——本轮不动。
4. **斜杠单键码 / 二级码**（`/t53`）——并入插入菜单的"二次过滤/二级项"逻辑（§3.3）。

### 6.1 AC 三分类（QG-1 修订）——用户可见票必须三类齐全
| 类别 | 形态 | 本文示例 |
|---|---|---|
| ① 存在 | 打开页面…之后…出现 X | "悬停块行后，手柄出现" |
| ② 生命周期 | 打开·切换·取消·外部点击·空态·关闭 六态 + **取消后无残留** | "插入菜单按 Esc 取消后，文档不含 `/`" |
| ③ 保真 | 可判真伪的**文本/样式/像素**结果 | "callout 标头文本严格等于『注释』不重复"；"字体色板显示彩色 A 字母" |

### 6.2 断言强度阶梯（QG-4 修订）
存在 → 可见 → **文本相等** → **状态往返** → **视觉**。渲染/装饰/插入/浮层类**至少到文本相等**；可取消类**必须到状态往返**。

### 6.3 视觉探针（QG-5 修订）
关键态（悬停高亮、菜单展开、表格编辑、色板）**截图 + 多模态复核**；"元素存在/count>0"**不算证据**；不得同类探针自证。
