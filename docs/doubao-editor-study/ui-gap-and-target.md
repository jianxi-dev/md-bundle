# 豆包编辑态 UI 设计 + 功能规格 → md-bundle 差距补齐（本仓自用）

> **性质**：本仓库**自己的**设计补齐基准文档（非 CW 移交物）。CW 只接收「问题 + 修复方案」用于工作流管控；**差在哪、改成什么样，是本仓要明确的项**，此文档即该定义。
> **基线**：豆包 `docs/doubao-editor-study/functional-spec.md` + `.lavish/doubao-editor-spec-v2.html`（v3 补录）；现状来自 2026-10-04 Playwright/bsk 实测。

## 0. 结论

我们不是「没做功能」，而是**只做了功能的「形」，丢了豆包三层骨架**：① 统一图标词汇；② 交互编排（hover 召唤、菜单结构、上下文分型）；③ 设计 token 阶梯。下表把豆包设计系统与功能规格逐面摊开，指出**每一面我们差在哪、应改成什么样**。

## 2. 逐面差距（差在哪 → 改成什么样）

### 2.1 编辑态基底（静默画布）
- **豆包**：正文区纯内容，无边框装饰；底色与阅读态同源。
- **现状**：`.cm-editor` 白底 `#fff`，与预览 `#fbfaf8` 不一致。
- **差距**：编辑画布底色未接入阅读态 token。
- **目标**：编辑 `.cm-editor` 底色 = `.preview-content` 底色（同 paper token）。
- **验收**：`getComputedStyle(.cm-editor).backgroundColor === getComputedStyle(.preview-content).backgroundColor`。

### 2.2 块手柄（P2 / P3）
- **豆包**：`42×26` 圆角药丸，**两段**=左「块型图标」(`.hover-block-type-icon-container`)+右「拖拽把手」(`.drag-handle`)；图标 18px，按块型切换（列表→列表图标、表格→`DataSheetOutlined`、高亮→callout 图标）；`left: 0; top:2px; height:26px; padding:0 3px; border:1px solid --border-soft; radius:6px`；`.bi/.gd` 各 `22×22`；默认 `opacity:0`，hover 淡入。
- **现状**：`20×20` 单图标；段落恒 `DragHandleOutlined`；表格块手柄实测也显示 `DragHandleOutlined`（未切 `DataSheetOutlined`）。
- **差距**：形态（单图标 vs 两段药丸）、尺寸（20 vs 42×26）、图标语义（无块型映射生效）。
- **目标**：手柄 = 42×26 药丸；左块型图标 + 右把手；`blockHandleIcon()` 对表格/列表/高亮等按 §3.2 表生效。
- **验收**：手柄 rect = 42×26；表格块 `data-icon=DataSheetOutlined`、列表 `DisorderListOutlined`、高亮 `CalloutOutlined`。

### 2.3 块菜单（P4 / P5）
- **豆包**：`min-width:236px; padding:5px; font-size:13px; radius:6px; 阴影`；项 `height:32px; padding:0 8px; gap:9px; radius:4px`；结构＝`问问豆包` → **转为图标网格**（§4.3 10 项两行，当前型蓝底）→ 面板项（缩进和对齐› / 颜色› / 评论 / 剪切 / 复制 / 翻译 / 删除 / 分享 / 复制链接 / 在下方添加›）；**按块型裁剪**（表格加 标题行/列·均分列宽；高亮 无颜色/翻译、加同步块）。
- **现状**（实测，含表格块）：宽 **144px**；文本＝`转换为 H1 H2 H3 H4 H5 H6 ¶ 缩进和对齐› 颜色› 类型› 上移 下移 复制块 删除块`。
- **差距**：① 宽 144≠236；② 转为网格仅 7 项（缺 有序/无序/待办/代码/引用/高亮，应 10 项）；③ **上下文未分型**——表格块菜单**无**标题行/标题列/均分列宽（用户报告「块菜单的表格不显示二级表格」）；非高亮块却出现 `类型›`；④ 缺「在下方添加›」（=插入菜单入口）；⑤ 位置在块**上方 25px**（U-09）。
- **目标**：菜单宽 236px、行高 32px；转为网格 10 项图标；按块型裁剪（表格加三项开关、高亮去颜色/翻译）；菜单顶端对齐块顶；补「在下方添加›」。
- **验收**：`menu.width=236`；表格块菜单含 `标题行/标题列/均分列宽`；转为网格 = 规格 10 项；`menu.y ≈ block.y`。

### 2.4 插入菜单（三入口合一，P0 / §5.4）
- **豆包**：空行「+」/ 块菜单「在下方添加›」/ 输入 `/`（或 `、`）**打开同一插入菜单**：分类列表（基础/常用/数据/绘图/团队协作/进阶/更多小组件），含**表格›尺寸选择器**（10×10，标题「插入支持富文本的表格」）、**分栏›栏数**、按钮›。
- **现状**：斜杠菜单为**单列图标网格 + 二级 flyout**（非豆包分类列表形态）；「表格」项**已有 10×10 网格**（`.mdb-slash-grid` 100 格，实测存在）；「分栏」flyout 仅 **ArrowRight/hover** 触发（Enter/点击不可用，F-02）；斜杠**快捷键 code 错**（分栏 = `flN` 应为 `fN`，U-10）；项用字符字形图标（F-01）。
- **差距**：形态（网格 vs 分类列表）、分栏入口不可用、快捷键语义、图标、缺三入口统一。
- **目标**：三入口共用同一菜单；分类列表形态；表格›/分栏› 悬停即展开；`/f3`=3栏。
- **验收**：三入口打开同一 `.mdb-slash-menu`；`/f3`、`/fl3` 语义按目标；「表格」→10×10、「分栏」→栏数 均可悬停展开。

### 2.5 表格（§7，最大缺口）
- **豆包**：① 块菜单 **表格专属**：标题行(开关)/标题列(开关)/均分列宽；② 滑入单元格 → 左上表块手柄（`DataSheetOutlined`）+ **行左/列顶淡点热点**，悬停变蓝「+」+ 气泡「插入行/列」+ 沿边界高亮线；③ **格内手柄**（滑入单元格左侧线浮现，空单元格为「+」）→ 悬停展开**插入菜单**；④ 单元格选区工具栏（合并/背景/对齐/BISU/代码/高亮/更多）。
- **现状**：① 块菜单无表格专属项（实测，见 2.3）；② 行「+」在首格内 10×10@x158 与行边界线错位 ~27px、列「+」是 467×12 整条横杠、**常显无 hover 门控**；③ 无格内手柄；④ 隐形 6px 边界覆盖层**吞单元格点击**（F-04）。
- **差距**：整层「表格专属能力」缺失 + 热点几何/门控错误。
- **目标**：补 标题行/列/均分；行列热点改 hover 蓝「+」贴边界；补格内手柄→插入菜单；边界层不遮编辑。
- **验收**：表格块菜单含三项开关；hover 单元格才现「+」且贴边界；点单元格中心落光标不插行。

### 2.6 色板（§4.5）
- **豆包**：字体色＝一排 `A` 色板（默认+8 色，`.swatches` `repeat(8,18px)`，`.cs.al` 透明底 A 字 15px/600）；背景色＝两排 16 格（首格无/斜线）；`恢复默认` 整宽按钮（`height:30px`）。
- **现状**：**块菜单**颜色 flyout =「红/蓝/绿/橙/紫 + 恢复默认」**5 个文字项**；**工具条**颜色 = `字体色 AAAAA` + `背景色 恢复默认`（A 字形，但色板与豆包不同）。
- **差距**：块菜单未用 A 色板；数量/色值不符（应 默认+8 字体色、16 背景色）；两套实现未统一。
- **目标**：统一「字体色 A×9 + 背景色×16 + 恢复默认」；色值∈豆包色板。
- **验收**：色板格数/色值与原型一致。

### 2.7 高亮块（§8.1）
- **豆包**：默认 🎉 + 琥珀底 `rgba(242,150,44,.28)`；类型/emoji 选择器；上下文菜单去颜色/翻译、加同步块。
- **现状**：callout 类型二级选项**有重复**（💡提示×2、⚠️注意×2 等，U-02）。
- **目标**：callout 类型集去重、与豆包对齐。
- **验收**：类型项 label 唯一。

### 2.8 分栏（§8.2）
- **豆包**：每栏滑入出现**块手柄**；栏沟 `.dragger`(2px)/命中区(12px) `col-resize`，悬停高亮、拖拽改宽；入口「分栏›选择栏数」。
- **现状**：`::: {.col-N}` 渲染 OK；栏沟拖拽已做；但**入口点击不可用**（F-02）、code 错（U-10）。
- **目标**：入口可用；余同现状。

### 2.9 选区工具栏（§6）
- **豆包**（表格选区）：问问豆包 / 合并单元格(单选禁用) / 单元格背景(›16色) / 转为▾ / 对齐▾ / B I S U 代码 / 高亮▾ / 更多 / 分享 评论。
- **现状**：`.mdb-floating-toolbar` 有 `字体色/背景色/对齐/清除/BSIU/链接/代码/分栏/复制/转为(…五级标题/正文/列表/任务/引用/代码/高亮/表格)`——结构较全；需核对**合并单元格**与**转为子菜单结构**。
- **目标**：对齐豆包项序与图标。

### 2.10 命令面板（⌘/Ctrl+K）
- **豆包 token**：行高 **32px**、4 的倍数、字 12px、菜单宽 236px。
- **现状**：面板 item **h=23px、gap=2px、padding `0 10px`、font 16px**（实测）。
- **目标**：行高/间距/字号对齐 token（32px / 4 倍数 / 12px）。
- **验收**：item h=32、gap∈4 倍数、font=12px。

### 2.11 交互编排（P0，横切全部浮层）
- **豆包**：hover 召唤、零点击；菜单/手柄/flyout 有明确「召唤—消退」时序；移出即收。
- **现状**：菜单打开后**不随指针离开消退**（父菜单常驻），并对指针所在块 **retarget 重开**（U-07）；手柄与文本仅 2px **过早弹菜单**（F-05）；滚动**不消退**（F-07）；近底部块菜单**不弹出**（U-03）。
- **目标**：统一「离开整栈即收 + 视口夹取/翻转 + 滚动消退 + 展开缓冲」。

## 4. 目标态清单（改成什么样，用于拆票验收）

1. **手柄**：42×26 两段药丸；块型图标按 §3.2 生效。
2. **块菜单**：236px / 行高 32px / 转为网格 10 项 / **按块型裁剪**（表格→标题行·标题列·均分列宽；高亮→无颜色·翻译）/ 顶端对齐块顶。
3. **插入菜单**：三入口共用；分类列表；表格›尺寸(10×10)、分栏›栏数 悬停即展；`/fN` 语义。
4. **表格**：行/列 hover 热点贴边界 + 蓝「+」气泡 + 边界高亮线；格内手柄→插入菜单；边界层不遮编辑。
5. **色板**：字体色 A×9 + 背景色×16 + 恢复默认；色值对齐豆包。
6. **高亮**：类型去重。
7. **基底/token**：编辑底 = 预览底；间距 4 倍数；面板行高 32px / 字 12px。
8. **编排**：hover 召唤 + 离栈即收 + 视口夹取/翻转 + 滚动消退 + 展开缓冲。
9. **图标**：全站统一 `svg data-icon`，命名 ∈ 豆包图标表。

## 5. 与 CW 的分工（明确边界）

- **本仓（本文档 + 缺陷目录）**：定义「差在哪、改成什么样」→ 拆票 → 开发 → 验证。
- **CW（工作流管控）**：只收**问题 + 修复方案**，用于加固门禁：
  1. `pr-automation.sh` G1 出口**机检** `.artifacts/<票>/state-coverage.json` + ≥4 张截图，缺则退 1；
  2. 交互票截图须经**多模态复核**（`multimodal-looker`/`visual-qa`）出结论附票；
  3. 新增**原型一致性测试层**（token/图标/几何/hover 门控断言）；
  4. 截图须**原型 vs 实现并排**；收紧 `no-ui-impact`。
- CW **不**消费本仓缺陷、**不**做本仓开发。

### 6.3 U-04 结论（更正）
块菜单**本身不显示任何快捷键**（仅 `title` 提示如「一级标题」）；使用者看到的是**斜杠菜单里的 markdown 源码触发符**（`#`/`>`/```` ``` ````/`{ }` 等，G-01）。这些在「点击式菜单」里用不上。
→ **目标**：菜单项显示**本产品自有快捷键**（来自 `keybindings.ts`，如 `⌘B`/`⌘⇧7` 等），或按豆包（图标即语义、不显快捷键）；**不得**再以源码语法充当「快捷键」提示。
