## 🔴 根本原因（已代码核实）

**11/12 功能只实现了库代码（`packages/editor`），未接入应用（`apps/web`）。**

核实命令：
```bash
grep -rn "contextToolbar|structureLinter|chapterReorg|commandPalette|floatingToolbar|registerToolbarCommands" apps/web/src/
# → 无任何结果
```

`apps/web/src/App.tsx` 只调用了 `editorDecorations()`，没有引用任何新功能。

**这直接解释了用户的绝大多数"无此功能"/"不知如何测试"反馈。**

## 分类发现

### A. 语义编辑态（R6）— 已接入但有 bug

| 用户反馈 | 期望 |
|----------|------|
| "移入后，整篇文章都自动切换" | 只有当前块切换 |
| "移出后不会自动恢复" | 自动恢复完全渲染 |
| "始终是源码" | 默认完全渲染 |
| "始终显示"（标记） | 非活动块隐藏标记 |
| "原格式，url 显示" | 非活动块隐藏 URL |
| "不通过，看到是识别后的#号和标题" | 非活动块隐藏 `#` |
| "语法不高亮，也无标签，源格式"（代码块） | 非活动块高亮 + 语言标签 |
| "有序列表前显示的还是圆点，不是数字" | 有序列表显示数字 |
| "光标在内，会显示灰色数字" | 活动态应显示淡色标记（这个方向对了） |
| "切换，在内容区切换显示 <!-- -->" | 需确认是什么 |

**诊断**：`decorations/index.ts` 的 per-block 逻辑已存在（`getBlocks` + `getBlockAt`），但渲染效果不符。需要实地调试。
