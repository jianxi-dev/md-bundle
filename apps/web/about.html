关于 MD-Bundle

纯前端在线工具：打开、编辑、导出 .md 与 .mdpkg。

这是什么

MD-Bundle 是一个 Markdown 自包含在线工具 —— 把图片、附件打包进一个 .mdpkg 文件，分享不再裂图。支持打开、编辑、导出 .md 与 .mdpkg。

渐晰（Jianxi）生态

  • mdpkg 格式 —— 自包含 Markdown 打包格式（规范 + CLI 参考实现）
  • MD-Bundle 网页 —— 本产品，浏览器端打开 / 编辑 / 导出
  • Clairis 桌面 —— 桌面旗舰产品，Markdown 阅读编辑与学习成长伙伴

开源

MD-Bundle 以 MIT 许可开源。源码见 github.com/jianxi-dev 组织。

隐私

Phase 1 无账号、无后端：文件处理全部在浏览器本地完成，不上传服务器。本地存储 （localStorage）仅用于界面状态，数据只留在你的浏览器里。
