格式规范

mdpkg —— 自包含 Markdown 打包格式。一文件带走全部图文，分享不再裂图。

什么是 .mdpkg

.mdpkg 是一种自包含的 Markdown 打包格式：把 Markdown 正文、图片、附件打包进 一个文件，分享时不再裂图。格式规范与 CLI 参考实现见 jianxi-dev/mdpkg。

包结构

一个 .mdpkg 是 ZIP 容器，包含以下条目：

package.mdpkg
├── document.md        # 入口 Markdown 文档
├── assets/red.png     # 资源文件（图片、附件）
├── includes/ch1.md    # include 片段（可选）
└── manifest.json      # 清单：文件路径 / sha256 / media_type
  • document.md —— 入口文档，默认渲染起点
  • 资源文件 —— 图片、附件等，按路径引用
  • manifest.json —— 清单：记录每个文件的路径、sha256 校验值、 media_type 媒体类型；schema 封闭（additionalProperties: false）， 未知字段直接校验失败

打开管线

浏览器端与 CLI 使用同一条管线，结果同构：

解包→ 校验→ include 展开→ 解析→ 符号转换→ 渲染（消毒）→ 内联
  • 解包 —— 读取 ZIP 条目
  • 校验 —— 格式合法性、sha256、引用闭包、外部引用计数
  • include 展开 —— <<< 引用展开，带循环检测
  • 解析 —— Markdown 解析
  • 符号转换 —— (tm) → ™ 等符号扩展，只作用于纯文本，不改写源文件
  • 渲染（消毒） —— HTML 消毒后输出
  • 内联 —— 图片以 data URI 内联，产物完全自包含

浏览器里的预览与 CLI mdpkg render 输出一致 —— 这是「网页预览」与「本地渲染」同构的前提。

校验

打开后返回校验报告：

  • ok —— 是否通过（errors 为空）
  • errors —— 硬错误：格式不合法、sha256 不匹配、引用外环等
  • warnings —— 软警告
  • externalCount —— 外部引用（http/https 链接）条数

校验失败不阻断渲染：校验问题单独呈现，HTML 照常生成。

写侧（打包）

packMdpkg 与 CLI mdpkg pack 共用同一 ZIP 逻辑（条目排序、压缩策略、 固定 mtime），产出字节与 CLI 一致。校验与哈希重算在内部完成，调用方无需手动维护 manifest.json。
