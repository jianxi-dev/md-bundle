图文打包演示

官方示例 · .mdpkg 格式 · 含图片资源

这是一个 .mdpkg 自包含 Markdown 打包文件 的示例页面。.mdpkg 格式将 Markdown 源码与图片资源打包进一个文件，分享不再裂图。

包内内容

  • main.md — Markdown 入口文档
  • manifest.json — 包元数据（entrypoint、extensions、source_url）
  • assets/ — 图片资源目录（PNG/SVG/WebP）

为什么需要 .mdpkg？

传统 Markdown 引用图片时使用相对路径（![img](./photo.png)），分享时需同时发送图片文件，容易裂图。.mdpkg 将图片以 data URI 内嵌到包中，一个文件带走全部图文。
