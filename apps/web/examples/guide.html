MD-Bundle 使用指南

官方示例 · Markdown 格式 · 16 行

三步完成一次图文分享：

  1. 打开：拖入 .md 文件，或选择 .mdpkg 包
  2. 导入图片：粘贴 / 拖拽 / 批量选择，图片自动入库并插入引用
  3. 保存：有图自动保存为 .mdpkg，一个文件带走全部图文

TIP：导出 .md 会丢失图片 —— 分享前请保存为 .mdpkg。

常见问题

为什么导出 .md 会提示丢失图片？

.md 是纯文本格式，无法携带图片。

.mdpkg 是什么？

自包含 Markdown 打包格式，图片以 data URI 内嵌。

.mdpkg 能还原成普通 Markdown 吗？

可以 —— 导出 .md 即可，但图片会丢失。
