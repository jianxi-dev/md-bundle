命令面板 · 重设计

现状是「520px 的 CSS 网格 + 无简介 + 键位被挤」，所以不好看也不好用。本页给出重设计与可交互原型：单列、键位右对齐、分组吸顶、最近使用、拼音搜索、底部键位提示。

01

为什么要保留它

你怀疑它存在的意义——我的判断是保留，但必须重做成"值得存在"的样子。

差异项

豆包没有

命令面板是我们的标志性能力；砍掉等于抹掉一处差异，而不是消除一个缺陷。

可发现性

快捷键的唯一全量入口

你要的"菜单里显示键位"，最完整的落点就在这里——40+ 命令的键位一览。

效率

比逐级菜单快

模糊 + 拼音，三四个键直达命令；不用记住它在哪个菜单。

04

设计规格

布局

单列 · 键位右对齐

一行一命令：图标名称简介 … 键位。名称左对齐、简介占中、键位固定最右，永不错位。

分组

吸顶分组 + 最近使用

格式 / 块 / 插入 / 视图 / 体检；顶部固定「最近使用」区，重复命令一步到位。

搜索

模糊 + 拼音 + 匹配高亮

首字母（jc→加粗）、全拼、子序列；命中的字高亮，一眼知道为什么命中。

导航

单列顺序导航

↑↓ 沿单列上下，不跨列；选中态 = 品牌淡底 + 左侧 2px 强调条。点分类 chip 可限定分组。

Token

沿用编辑器设计变量

primary #7b86ea、bg2 #0e0f12、border rgba(255,255,255,.08)、行高 42、圆角 14/9/6。

状态

默认 / 筛选 / 空态 / 最近

空态给建议 chip；筛选实时；Esc/点外部关闭且无残留（对齐 QG-1 生命周期）。
