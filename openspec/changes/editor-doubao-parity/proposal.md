## Why

md-bundle 编辑器的「编辑态」块级操作手感与内容丰富度明显弱于豆包文档（实测对比），用户要求对标补齐：块手柄有死区、工具条缺「整段转换」、斜杠菜单是文字列表、表格在编辑态是裸源码、高亮块切源码且末字符后吞输入、分栏只有 2/3 栏、缺缩进与视频/文件、快捷键仅 5 个。此变更一次性把编辑态体验对齐豆包，避免继续零散修补。

## What Changes

- **块级入口手感**：块手柄粘性常显（跨空行/滚动/移到手柄都保持）、扩大命中区 + 命中桥接、按块类型显示图标、菜单图标化、空行也显示「＋」插入入口。
- **工具条**：新增「整段转换」（选中部分也作用于整段、支持多行），转换目标补齐（列表/任务/引用/代码/高亮/表格）；移除「字体」下拉；文字颜色改弹出双色板（字体色 + 背景色 + 恢复默认）；对齐等改弹出面板。
- **插入与块类型**：斜杠菜单改图标网格 + 二级 flyout + 可打字筛选；新增斜杠单键首字母码与二级码；触发键支持「/」与「、」；命令面板（Ctrl/⌘+K）改网格并显示快捷键 + 简介/样式预览；新增加任务/转任务 + 可点击勾选；新增缩进/反缩进；新增视频/文件嵌入。
- **表格**：编辑态呈现预览态表格 widget、单击单元格进入编辑、悬停列上方/行左侧「＋」加行/列、单元格内可用完整插入菜单。
- **高亮块**：改为渲染态内联编辑（不切整块源码），修复光标到末字符后吞输入。
- **分栏**：支持 1–5 栏，提供可视化栏数选择器。
- **快捷键体系**：行内 Markdown 快捷 + 功能键组合（含标题级别、列表/任务、代码块等）。

## Capabilities

### New Capabilities

- `editor-insert-menu`: 斜杠插入菜单与命令面板——图标网格、二级 flyout、可筛选、单键首字母码与二级码、触发键「/」与「、」、Ctrl/⌘+K 网格（含快捷键与简介/样式预览）。
- `editor-shortcuts`: 编辑态快捷键体系——行内 Markdown 快捷、功能键组合、斜杠码约定与冲突规则。
- `editor-table-editing`: 编辑态表格预览态 widget——单击单元格编辑、悬停加行/列、单元格内插入块。
- `editor-callout-editing`: 高亮块渲染态内联编辑——不切换源码、修复边界吞输入。
- `editor-columns`: 分栏布局 1–5 栏 + 可视化栏数选择器。
- `editor-block-types`: 块模型与块级能力扩展——heading 分级、task 类型、加任务/转任务、复选框可切换、缩进/反缩进、视频/文件嵌入。

### Modified Capabilities

- `block-editing-entry`: 手柄显隐由 hover-only 改为粘性常显、扩大命中区、按块类型显示图标、空行显示「＋」、菜单图标化。
- `selection-toolbar`: 新增整段转换、扩充转换目标、移除字体选择器、颜色改弹出双色板、对齐等改弹出面板。

## Impact

- `packages/editor`：块手柄（`block-handle*`）、浮动工具栏（`floating-toolbar`）、斜杠菜单（`slash`）、命令（`commands`）、键位（`keybindings`）、块模型（`block-model`）、高亮块装饰（`decorations/callout`）、新增表格 widget、新增分栏命令扩展、工具栏上下文（`toolbar`）。
- `packages/renderer`：表格/高亮块/HTML 预览样式；视频/文件嵌入的消毒白名单需一并决策。
- `apps/web`：接线与 e2e（用户可见验收，QG-1/QG-2）。
- 测试：`packages/editor/test/*.test.ts`（公共 API 接缝）+ `apps/web/test/*.spec.ts`（最高接缝）。
- 不改变文件格式与导出管线；`@md-bundle/renderer` 的渲染 SSOT 不变。
- 关联 spec issue：#271。
