## Why

上一轮 `editor-doubao-parity` 把块手柄、斜杠菜单、表格、高亮块、分栏、快捷键等**功能接上了**（21 票全绿并归档），但用户打开页面实际使用时，编辑态体验**系统性劣化**：编辑态不如预览态好看、控件要点击才出现、表格点一下就塌成裸源码、高亮块标题重复成「注释 注释」、斜杠菜单点外部不关、取消后文档残留 `/`、插入的表格是 `A/B/1/2/3/4` 玩具占位。

根因两层：**编辑态与预览态两套渲染 + 两套样式分叉**（架构性），叠加**验收停在"元素存在"**（presence 自证拦不住文本残留 / 不关闭 / 坍缩）。本轮把编辑态升级为「预览态渲染 + 活动块源码」，并据此系统性修正交互保真、收口历史缺陷，同时以本轮作为 QG-1..QG-8 的**验收靶场**。

## What Changes

- **编辑 = 预览（根因解法）**：编辑态逐块调用共享渲染管线（`renderMarkdown`）产出与预览/导出**完全相同**的 HTML；编辑态内容区套用与预览同源的样式作用域；光标所在块显示源码（活动块源码桥），离开回渲染态；按块增量渲染 + 缓存。
- **手柄 / 块菜单**：控件**悬停即显、点击只用于确认动作**；命中桥接（手柄→菜单移动不消失）；按块型显示图标；上下文分型；`缩进和对齐 ›` / `颜色 ›` 二级。
- **插入菜单与快捷输入**：触发键 `/` 与 `、`（含 IME 守卫）；分类纵向列表；打开后**继续输入即二次过滤**（中文名 / 拼音 / 单键码 / **二级项直达**）；表格 `›` 尺寸选择器、分栏 `›` 栏数选择器；Esc / 外部点击取消且**无残留**；空态可退出。
- **表格（不坍缩源码）**：保持可视化表格 + 单元格内可编辑；格内手柄悬停→**插入菜单**；行/列锚点在**格间线**（边界线高亮）；标题行/列开关；均分列宽；真实尺寸。
- **高亮块**：卡片内联编辑（不坍缩）；标头 = emoji + label（**不重复**）；类型 / 颜色 / emoji 走二级菜单。
- **分栏**：每栏滑入出现块手柄；栏沟可拖拽（col-resize）改宽；栏数 1–5。
- **其余能力**：任务可勾选；视频/文件渲染卡片/播放器；Mermaid 流程图编辑预览 + 渲染出图（不坍缩）；统一图标系统（`<svg data-icon>` 映射表）。
- **快捷键与命令面板**：菜单中显示键位（**仅图标项除外**）；命令面板由 CSS Grid **重设计为单列**（键位右对齐 + 分组吸顶 + 最近使用 + 拼音/模糊高亮 + 底部提示）。**注意：此项显式反转上一轮 4.3 的网格形态。**
- **缺陷收口**：D1–D10 全部转 tracked 并修复（`.md` 打开进编辑、标头重复、围栏反引号、菜单不关、空态驻留、取消残留、表格坍缩、玩具表格、空态无入口、React 重复 key）。
- **验收基建**：三分类 AC 模板 + 断言强度阶梯 + 视觉探针 + 生命周期黑盒巡检。

## Capabilities

### New Capabilities

- `editor-render-parity`: 编辑态与预览态的渲染/样式单一事实来源——逐块 `renderMarkdown`、共享样式作用域、活动块源码桥、按块增量渲染与缓存（编辑=预览）。

### Modified Capabilities

- `block-editing-entry`: 手柄显隐由"需点击/常显"改为**悬停驱动**；命中桥接；上下文分型（列表/高亮/表格各不同）。
- `selection-toolbar`: 颜色面板改为**彩色「A」字母**（字体色）与色块（背景色）+ 恢复默认；补单元格背景色与合并单元格。
- `editor-insert-menu`: 新增**二次过滤含二级项直达**；Esc/外部点击**取消无残留**；关闭语义（外部点击/移走即关）；**空态可退出**；命令面板由网格重设计为**单列**。
- `editor-table-editing`: **不得坍缩源码**；格内手柄悬停→插入菜单；行/列锚点改到**格间线**；标题行/列开关；均分列宽；真实尺寸（非玩具占位）。
- `editor-callout-editing`: 标头**不得重复**（emoji + label）；类型/颜色/emoji 走二级菜单；卡片内联编辑（含末字符后续输）。
- `editor-columns`: 每一栏滑入出现块手柄；栏沟**可拖拽改宽**（col-resize）。
- `editor-block-types`: 视频/文件渲染为卡片/播放器；Mermaid 流程图编辑预览 + 渲染出图，**不得坍缩源码**。
- `editor-shortcuts`: 菜单项**显示键位**（含快捷键的动作），仅图标项除外；命令面板复用同一命令注册表。

## Impact

- **`packages/editor`**：装饰层（表格 / 高亮块 / 代码 / 列表等）、块手柄与块菜单、斜杠与智能输入、命令面板、键位、浮动工具条、工具栏、主题。
- **`packages/renderer`**：`renderMarkdown` / `readerCssText` 被编辑态复用为渲染/样式 SSOT（新增编辑态接入，不动导出语义）。
- **`apps/web`**：编辑器扩展注册与命令面板挂载的接线；`.md` 打开落点改编辑态（D1）；空态「新建空白文档」入口（D9）。
- **e2e / 单测**：扩展 `apps/web/test/*.spec.ts`（QG-2）；`packages/editor` Vitest 单测。
- **不做**：分享 / 协作 / 同步块 / 多维表格族 / 团队协作块 / 进阶小组件 / AI 类；三模式工作区、多页签、FSA 文件夹、主题三态、邀请链接本轮不动。
