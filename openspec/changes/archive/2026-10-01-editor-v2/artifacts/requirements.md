# editor-v2 需求四要素

> Spec issue: #134
> Change: editor-v2

## What（做什么）

将 md-bundle 从"Markdown 编辑器"战略重定位为"文档平台"，编辑器是手段，`.mdpkg` 是可运行文档工件。

核心交付：
1. **安全底座修复** — DOMPurify 修复 + CSP + API key 内存存储 + CSS 隔离
2. **`.mdpkg` 即应用** — 包内自带渲染器 + CSS，双击打开即成品
3. **Diff-native AI** — 选中 → 改写 → 行内 diff → 逐 hunk 审阅
4. **结构体检 + 章节重组** — AST 规则诊断 + 拖拽重排
5. **语义编辑态** — 渐进式语法揭示（块级语义化）
6. **富表现力增强** — 视觉模板库 + HTML 块嵌入 + CSS-only 组件
7. **流式编辑** — 打字即渲染 + 选择即操作

## Why（为什么做）

当前产品在"编辑器"红海中与 Typora/Obsidian/豆包竞争，无法形成差异化。真正护城河是 `.mdpkg` + 同源渲染 + 零后端 + 中文原生，竞品结构性无法复制。

代码库存在安全硬伤（DOMPurify 允许任意 style/id、全仓无 CSP），必须先修复。

## Scope（范围）

### 包含
- 安全底座修复（DOMPurify、CSP、API key、CSS 隔离）
- `.mdpkg` 包格式升级（内联渲染器 + 样式）
- Diff-native AI（行内 diff 审阅）
- 结构体检（AST 规则诊断）
- 章节重组（拖拽重排）
- 语义编辑态（渐进式语法揭示）
- 上下文感知工具栏
- 智能输入（快捷输入 + 智能 Enter/Backspace + 自动配对）
- 视觉模板库（Callout 12+ 类型 + 布局模板）
- HTML 块嵌入（安全子集 + `@scope` 隔离）
- CSS-only 组件（折叠/标签/进度条）
- 流式编辑（打字即渲染 + 选择即操作）

### 不包含
- 意图引擎（主动 LLM 建议）
- 文档指纹
- 动态内容块 + 数据源
- AI 代理（静默自主）
- 内联 SVG
- 自定义元素（md-tabs 等）
- 导出时剥离增强层
- 协作编辑（多人实时）
- 插件系统

## Non-goals（非目标）

- 不做"更好的编辑器"，做"更好的文档平台"
- 不追求功能全面，聚焦护城河
- 不依赖 AI，AI 是可选增强
- 不引入私有语法，保持 Markdown 可移植性
- 不做实时协作，保持零后端
