## 1. 前置（架构与图标）

- [x] 1.1 **编辑=预览落座（W0，非破坏对齐）**：编辑态内容区套用预览同源样式作用域 + 容器盒，并逐类修正既有装饰（heading/list/quote/code/表格/高亮块视觉）的排版与盒模型，**不替换块 DOM**；活动块显示源码、离开回渲染态。用户打开含标题/列表/引用/代码/表格/高亮块/公式的文档，编辑态与预览态**逐块计算样式相等**，且块手柄/选区浮条/结构体检等既有行为**不回归**（全量 e2e 通过）。（依赖 design.md D1；无新增跨包导出）
- [x] 1.2 **图标系统（W1）**：建立"块型→图标""动作→图标"映射（`<svg data-icon>`，viewBox 24×24、currentColor），替换零散字符/简易 SVG；手柄显示块型图标、空行「＋」=`AddOutlined`、字体色为彩色「A」。用户看到手柄图标随块型变化。

## 2. 块级入口（手柄与菜单）

- [x] 2.1 **块手柄悬停即显（W2）**：悬停块行手柄淡入、悬停手柄自动展开块菜单（块获选中态）、手柄→菜单命中桥接不消失、空行显示「＋」。用户不点任何东西，滑过即见手柄与菜单。（依赖 1.2）
- [x] 2.2 **块菜单上下文分型 + 二级（W3）**：转为图标网格；按块型给不同菜单；`缩进和对齐 ›`、`颜色 ›`、高亮块类型二级 flyout。用户悬停二级项即展开子面板。（依赖 1.2、2.1）

## 3. 插入菜单与快捷输入

- [x] 3.1 **插入菜单形态与过滤（W4a）**：`/` 与 `、` 触发（含 IME 守卫）；分类纵向列表（基础/常用/绘图）；打开后继续输入即二次过滤（中文名 / 拼音 / 单键码 / **命中二级项直达**）；无匹配显示"无匹配项"且可退出。用户输入 `biao` 或 `/t` 即筛到目标。（依赖 1.2）
- [x] 3.2 **插入菜单二级与生命周期（W4b）**：表格项悬停展开尺寸选择器（网格选行列，直接点插 2×3）、分栏项悬停展开栏数选择器；Esc / 外部点击 / 光标移走即关闭且**取消后文档无 `/`、`、` 残留**。用户取消后文档干净。（依赖 3.1）

## 4. 表格

- [x] 4.1 **表格保真（不坍缩）（W6）**：点单元格/编辑内容**不塌成裸源码**；格内手柄悬停→**插入菜单**（非块菜单，教训 T-1）；行/列插入锚点在**格间线**（边界线高亮 + 气泡，非整行整列底色）；表块菜单含标题行/标题列开关、均分列宽；插入表格有真实尺寸（非 `A/B/1/2/3/4`）。用户点单元格仍在可视化表格里编辑。（依赖 1.1、2.2）

## 5. 高亮块

- [x] 5.1 **高亮块保真（W7）**：卡片内联编辑（**不坍缩** `> [!NOTE]` 源码）；标头 = `emoji + label` **不重复**（不出现「注释 注释」）；末字符后仍可续输；类型/颜色/emoji 走二级菜单。用户点卡片直接编辑、标头只显示一次。（依赖 1.1、2.2）

## 6. 分栏 / 任务 / 视频文件 / 流程图

- [x] 6.1 **分栏保真（W8）**：每一栏滑入出现块手柄；栏间是**可拖拽栏沟**（col-resize），按住左右拖拽改栏宽并回写源码。用户拖动栏沟即改变栏宽。（依赖 1.2）
- [x] 6.2 **任务可勾选（W9）**：编辑态复选框直接可点击，勾选切换源码 `- [ ]`/`- [x]` 且文字变灰。用户点一下即勾选。
- [x] 6.3 **视频/文件 + 流程图（W10）**：视频/文件渲染为可识别卡片/播放器；Mermaid 流程图编辑态预览 + 渲染态出图，**不坍缩源码**。用户插入后直接看到卡片/图。（依赖 1.1）

## 7. 选区工具栏

- [x] 7.1 **选区工具栏保真（W5）**：字体色用**彩色「A」字母**、背景色用色块、恢复默认；表格选区含合并单元格（多格启用）与单元格背景色。用户一眼可辨颜色选项。（依赖 1.2）

- [x] 8.1 **快捷键在菜单中显示（W11a）**：菜单项显示键位，**仅图标项除外**。用户在菜单里直接看到 `复制 ⌘C` 这类键位。（依赖 2.2、3.1）
- [x] 8.2 **命令面板重设计（W11b）**：单列 + 键位右对齐 + 分组吸顶 + 最近使用 + 模糊/拼音/命中高亮 + 单列顺序导航 + 底部键位提示 + 空态建议。用户打开面板看到清爽单列。（依赖 1.2；**显式反转上一轮 4.3 的网格形态**）
